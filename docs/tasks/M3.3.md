# M3.3 — UNKNOWN gate dan audit entry

Status: SELESAI pada 2026-09-15. Basis: M3.2 terverifikasi.

## Lingkup

Satukan keputusan universe dan security menjadi gate entry fail-closed yang immutable dan
dapat diaudit. Tidak ada intent, quote, signer, execution, atau transaksi.

## Acceptance criteria

- Entry hanya diizinkan bila universe eligible dan security `PASS`.
- Security `UNKNOWN` atau `REJECT` selalu memblokir entry.
- Alasan universe dan security diberi namespace agar dapat ditelusuri tanpa ambigu.
- Keputusan menyimpan timestamp UTC dan snapshot keputusan upstream.
