# M3.2 — Security adapter

Status: SELESAI pada 2026-09-15. Basis: M3.1 terverifikasi.

## Lingkup

Tambahkan boundary provider security read-only dan gate fail-closed. Tidak ada provider
HTTP nyata, scheduler, intent, signer, atau transaksi.

## Acceptance criteria

- Hasil hanya `PASS`, `REJECT`, atau `UNKNOWN`; hanya `PASS` yang mengizinkan entry.
- Evidence fresh dan lengkap memeriksa mint authority, freeze authority, program support,
  dan tradability.
- Flag kontrol gagal menghasilkan `REJECT` dengan alasan eksplisit.
- Evidence tidak ada, tidak lengkap, invalid, stale, dari masa depan, atau provider error
  menghasilkan `UNKNOWN`.
- Evidence menyimpan source, waktu, slot, rule version, dan alasan keputusan.

## Bukti

- `uv run --isolated --python 3.11 --with 'psycopg[binary]>=3.2,<4' python -m unittest tests.test_security tests.test_discovery tests.test_feed`: 9 tes lulus.
- `uv run --isolated --python 3.11 --with 'psycopg[binary]>=3.2,<4' python -m unittest discover -s tests`: 24 tes lulus, 7 integration test PostgreSQL di-skip karena `PGPASSWORD` tidak tersedia pada sesi ini.
- Pembuktian akhir M3: suite penuh 27/27 tes lulus pada PostgreSQL lokal pada 2026-09-16, tanpa skip.

## Serah terima

M3.2 selesai. M3.3 berikutnya menyatukan gate `UNKNOWN`/`REJECT` dengan audit keputusan
entry; tetap tanpa execution atau transaksi.
