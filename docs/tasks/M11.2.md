# M11.2 — Deviasi paper

## Kontrak

`compare` membandingkan satu outcome sinyal dengan outcome paper tanpa
mengeksekusi transaksi dan tanpa menghasilkan probabilitas.

Input wajib:

```json
{
  "signal_id": "uuid-atau-id",
  "signal_outcome": "TP_FIRST",
  "paper_outcome": "TP_FIRST",
  "signal_timestamp": "2026-01-01T00:00:00Z",
  "paper_timestamp": "2026-01-01T00:05:00Z"
}
```

Outcome yang diterima adalah nilai `Outcome` dari `meme_ai_trader.labels`:
`TP_FIRST`, `SL_FIRST`, `TIMEOUT`, `EXIT_UNAVAILABLE`, atau
`DATA_INSUFFICIENT`. Timestamp harus ISO-8601 atau `datetime` timezone-aware.

Signal window dimulai pada `signal_timestamp` dan berakhir secara inklusif
setelah `window_seconds` (default 3600 detik). `paper_timestamp` di luar
window adalah deviasi meskipun outcome sama.

Output selalu berupa objek dengan format:

```json
{
  "signal_id": "uuid-atau-id",
  "status": "MATCH",
  "reason": "outcome sama dalam signal window"
}
```

`status` hanya boleh `MATCH`, `DEVIATION`, atau `INSUFFICIENT_DATA`:

- `INSUFFICIENT_DATA`: signal id, outcome, timestamp, atau window hilang/tidak valid.
- `MATCH`: kedua outcome sama dan kedua timestamp valid dalam window.
- `DEVIATION`: outcome berbeda atau timestamp paper berada di luar window.

Perbedaan timestamp di dalam window tidak dianggap deviasi. Kontrak ini hanya
membandingkan hasil; ia tidak mengubah modul paper/simulator atau fitur milestone
sebelumnya.
