# M12.1 — Snapshot on-chain read-only

## Batas

Modul ini hanya menormalisasi dan menilai snapshot data Solana. Ia tidak
memiliki wallet, signer, keypair, atau jalur pengiriman transaksi. Snapshot
yang lolos hanya bukti data untuk analisis; keputusan transaksi tetap di luar
scope.

## Schema

```json
{
  "schema_version": 1,
  "chain": "solana",
  "network": "mainnet-beta",
  "mint_address": "11111111111111111111111111111111",
  "observed_at": "2026-09-21T12:00:00Z",
  "source": "solana-rpc",
  "rpc_slot": 123456789,
  "commitment": "confirmed",
  "token_supply": "1000000",
  "decimals": 6,
  "mint_authority": null,
  "freeze_authority": null,
  "holder_count": null,
  "top_holder_ratio": null,
  "liquidity": null,
  "liquidity_locked": null,
  "data_status": "FRESH",
  "missing_fields": [],
  "warnings": []
}
```

Nilai yang tidak tersedia tetap `null`; tidak pernah diubah menjadi nol atau
diestimasi. `network` harus salah satu `mainnet-beta`, `devnet`, `testnet`,
atau `localnet`; `chain` harus `solana`. `schema_version` saat ini `1`.

## Hard safety fields

Field berikut wajib ada dan valid untuk snapshot yang dapat diteruskan:

`schema_version`, `chain`, `network`, `mint_address`, `observed_at`, `source`,
`rpc_slot`, `commitment`, `token_supply`, `decimals`, `mint_authority`, dan
`freeze_authority`.

Authority bernilai `null` boleh jika provider menyatakan authority memang tidak
ada; key-nya tetap harus hadir. Field `holder_count`, `top_holder_ratio`,
`liquidity`, dan `liquidity_locked` adalah pendukung. Field pendukung yang
hilang dicatat pada `missing_fields` dan menghasilkan `PARTIAL`, tetapi hard
safety yang tidak lengkap menghasilkan `INVALID`.

## Freshness dan commitment

`max_snapshot_age_seconds` default `120` dan dapat dikonfigurasi. Umur adalah
`current_time - observed_at`; timestamp masa depan lebih dari toleransi default
5 detik menjadi `INVALID`. Status yang mungkin: `FRESH`, `STALE`, `PARTIAL`,
`MISSING`, dan `INVALID`.

- `FRESH`: hard safety valid, pendukung lengkap, dan umur dalam batas.
- `PARTIAL`: hard safety valid tetapi field pendukung hilang.
- `STALE`: snapshot valid tetapi umur melewati batas.
- `MISSING`: snapshot utama tidak tersedia.
- `INVALID`: schema, timestamp, mint, slot, commitment, nilai, network, atau
  konsistensi identitas tidak valid.

Commitment yang diterima hanya `confirmed` (default pemantauan cepat) dan
`finalized` (verifikasi outcome/pelaporan). `processed` ditolak. `expected_mint`
dan `expected_network`, jika diberikan, harus sama persis dengan snapshot;
perbedaan network, mint, atau identitas slot ditolak.

`allows_signal` hanya mengembalikan true untuk `FRESH` atau `PARTIAL` dengan
seluruh hard safety fields valid. `STALE`, `MISSING`, dan `INVALID` selalu
false; tidak ada fungsi transaksi pada modul ini.
