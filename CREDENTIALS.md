# Credentials

- Rahasia hanya dibaca dari environment proses lokal; tidak ada secret di source, Git, dokumentasi, atau log.
- `BIRDEYE_API_KEY` diperlukan hanya bila `MEME_AI_BIRDEYE_ENABLED=true`.
- Password PostgreSQL digunakan hanya untuk koneksi/test lokal dan tidak dicatat di sini.
- Private key/signing credential dilarang sampai milestone execution dan aktivasi eksplisit.

Lihat `README.md` untuk konfigurasi non-rahasia dan `AGENTS.md` untuk batas safety.
