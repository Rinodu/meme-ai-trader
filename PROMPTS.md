# Prompt kerja

## Memulai paket

```text
Baca AGENTS.md, AI_CONTEXT.md, docs/tasks/CURRENT.md, dan PRD.md. Periksa folder proyek dan lingkungan Windows yang tersedia. Kerjakan hanya M1.1 sesuai kontrak CURRENT.md sampai gate yang relevan terpenuhi. Jangan menganggap source code atau alat sudah terpasang. Catat temuan, perbarui dokumen, lalu commit dan push ke branch tugas jika remote dan autentikasi tersedia. Jika belum, selesaikan bagian lokal yang bisa dilakukan dan laporkan hambatannya. Beri laporan singkat; jangan mulai subtugas berikutnya.
```

## Melanjutkan

```text
Lanjutkan satu subtugas berikutnya yang prasyaratnya lulus di ROADMAP.md. Baca konteks minimum sesuai AGENTS.md, verifikasi status aktual, dan tetapkan CURRENT.md sebelum edit. Implementasikan, uji dampaknya, perbarui dokumen, commit dan push branch tugas. Laporkan bukti serta langkah berikutnya; berhenti setelah satu subtugas.
```

## Memperbaiki bug

```text
Perbaiki bug berikut: [gejala dan langkah reproduksi]. Cari akar masalah pada kode relevan, buat reproduksi minimal bila diperlukan, dan pertahankan kontrak FEATURES.md. Jangan refactor modul lain atau melemahkan tes. Jalankan tes terdampak, catat hasil dan keterbatasan, commit/push branch tugas sesuai aturan.
```

## Menambah fitur

```text
Saya ingin fitur: [perilaku yang diinginkan]. Petakan ke roadmap dan kontrak fitur. Jika mengubah perilaku fitur lama, jelaskan pilihan/dampaknya dahulu sebelum implementasi. Jika kompatibel dan lingkup jelas, kerjakan satu subtugas dengan acceptance criteria, tes, dan dokumentasi yang relevan.
```

## Audit milestone

```text
Audit milestone [ID] terhadap acceptance criteria, fitur, kode, dan bukti tes aktual. Baca bagian relevan saja. Pisahkan PASS, FAIL, BLOCKED, dan INCONCLUSIVE. Jangan mengklaim gate selesai hanya berdasarkan checklist. Perbaiki kekurangan dalam lingkup tugas ini; jangan menambahkan fitur baru. Laporkan kesiapan lanjut.
```

## Serah terima sesi

```text
Perbarui AI_CONTEXT.md dan CURRENT.md berdasarkan keadaan aktual: yang selesai, bukti pemeriksaan, masalah, status Git/push, dan satu langkah berikut. Jangan menyalin seluruh riwayat. Jangan tandai DONE jika tes wajib belum lulus.
```

## Pembaruan progres setiap tugas

```text
Perbarui PROGRESS.md setelah subtugas ini selesai atau terhambat: status, checkbox pemeriksaan, bukti tes/commit/push, persentase dari jumlah subtugas selesai, dan riwayat singkat. Sinkronkan status terkait. Jika ada regresi fitur lama, buka kembali tugas/fiturnya dan perbaiki sebelum lanjut. Tampilkan hanya ringkasan checklist di chat.
```
