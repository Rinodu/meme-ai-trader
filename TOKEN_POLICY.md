# Token policy

Gunakan konteks minimum: `AGENTS.md`, `AI_CONTEXT.md`, dan `docs/tasks/CURRENT.md`, lalu hanya file relevan. Gunakan Serena untuk navigasi simbol bila tersedia, RTK untuk output terminal besar, Ponytail untuk implementasi minimal, dan `rg`/patch terarah sebagai fallback. Jangan membaca seluruh repo atau menduplikasi hasil tool tanpa kebutuhan.
